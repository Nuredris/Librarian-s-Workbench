Instructions

  • Set up the classification first: open Settings and choose LCC or DDC. Then set the Cutter Digits, whether to add a title workmark and a period before the Cutter, the initial articles to skip, and your location codes. Choose Back to return here.
  • Add items with + Add Row below the table, or Import a CSV, TSV or Excel file. Use Import ▸ Download import template to get the right columns.
  • Fill in the table cells (Location, Class, Surname, Given name, Title, Year, Volume) and the Cutter # and Call # columns fill in automatically, using the classification and Cutter table chosen in Settings. Click a cell to type. Enter or Tab saves, and Esc cancels.
  • Your own Cutter: type over a Cutter # to use your own number; it shows in purple italics. Clear it to go back to the generated one. With DDC, the ↗ beside each Cutter copies the name and opens an online Cutter-Sanborn lookup.
  • # of copies prints one label per copy, ending c.1, c.2 and so on. Leave it blank for no copy number.
  • Delete by ticking two or more rows, or the box in the header to select all, then choose Delete selected.
  • Preview shows the spine labels at actual size. Adjust paper, font, cell size and margins there, then choose Print to save a PDF.
